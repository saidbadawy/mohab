### ✨ مميزات الموقع

1. **ختم الشمع الملكي (افتح الدعوة):**
   - واجهة فتح المظروف التفاعلية مع مؤثرات قصاصات الذهب والأزهار (Confetti) عند الدخول.
2. **عداد تنازلي ذكي ودقيق (Live Countdown Timer):**
   - يحسب الأيام والساعات والدقائق والثواني حتى موعد بدء الحفل تماماً (٤ ديسمبر ٢٠٢٦ - ٧:٠٠ مساءً).
3. **تأكيد الحضور (RSVP) + إرسال عبر واتساب:**
   - نموذج لتسجيل اسم الضيف وعدد المرافقين ورسالة التهنئة.
   - زر مباشر لإرسال رسالة جاهزة عبر WhatsApp إلى مهاب أو رنا لتأكيد الحضور بضغطة زر.
   - حفظ تأكيد الحضور في المتصفح وعرض بطاقة تأكيد مميزة.
4. **دفتر التهاني والتبريكات (Guestbook):**
   - يمكن للضيوف ترك أطيب الأمنيات والمباركات لتظهر مباشرة على شاشة الموقع.
5. **خريطة تفاعلية وأزرار توجيه:**
   - خريطة Google Maps مدمجة داخل الصفحة.
   - زر لفتح الموقع مباشرة في تطبيق الخرائط، وزر لنسخ العنوان بضغطة واحدة.
6. **إضافة التذكير للتقويم (Calendar Integration):**
   - زر الإضافة المباشرة لـ Google Calendar.
   - زر تحميل ملف تذكير التقويم (.ics) المتوافق مع هواتف iPhone (Apple Calendar) و Outlook.
7. **مشغل موسيقى هادئة ورومانسية:**
   - موسيقى بيانو ناعمة تعمل بمحرك Web Audio بدون انقطاع أو حاجة لملفات خارجية، مع إمكانية التشغيل والكتم بسهولة.
8. **تساقط بتلات الورد الطبيعية (Floating Rose Petals):**
   - مؤثرات بصرية ناعمة لخلفية رومانسية تليق بالمناسبة.
9. **متجاوب 100% مع الهواتف الذكية:**
   - مصمم ليظهر بأعلى درجات الفخامة على أجهزة iPhone و Android وشاشات الكمبيوتر.
